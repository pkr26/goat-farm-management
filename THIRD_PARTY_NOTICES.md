# Third-party notices

This project includes third-party software under its own license terms. The
authoritative component inventory for a distributed version is the set of
per-platform SPDX JSON SBOMs attached to that immutable GitHub release and the
OCI SBOM/provenance attestations attached to its signed image digests.

Before a release, the workflow regenerates SBOMs from the exact scanned image
bits. Reviewers must investigate changed licenses and ensure required notices
or source offers accompany distribution. Do not copy a dependency's license
text into this file without verifying the exact distributed version and its
upstream notice requirements.
